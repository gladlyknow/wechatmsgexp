# 功能对齐与兼容性说明

更新日期：2026-10-16。

## 当前主链路

| 能力 | Ubuntu 微信 4.x | Windows 微信 4.x | Windows 微信 3.x |
|---|---|---|---|
| 数据目录与账号探测 | 已实现并实机验证 | 保留原 4.x 探测适配器 | 保留原项目入口 |
| 数据库取钥 | Linux `/proc` 受限辅助程序，实机 20/20 | 保留 `Config.Cipher`/旧版扫描路径 | 使用原项目流程 |
| WAL 安全快照与解密 | 已实现并实机 20/20 | 共用 4.x 解密器 | 使用原项目流程 |
| 多账号统一档案 | 已实现，账号严格隔离 | 可复用 | 暂未迁移到统一档案 |
| 增量去重与来源追踪 | 已实现 | 可复用 | 暂未迁移到统一档案 |
| 图片、语音、视频、表情 | 已实机还原和解码验证 | 转码层可复用，待 Windows 回归 | 保留原项目能力 |
| 本地现代化界面 | 已实现 | Python 环境可运行，待实机回归 | 原项目界面仍保留 |
| 年度统计与报告 | 已实现，完全离线 | 可复用 | 需先进入统一档案 |

Linux 是本分支的默认实测路径；对 Windows 的既有代码不做删除或强制迁移。
未经过当前机器验证的 Windows 项目明确标为“保留/可复用”，不冒充已验收。

## 明确未实现或受源数据限制

- DOCX：原项目中的相关入口并非稳定的 4.x 富媒体导出链路，本阶段没有伪装为可用。
  若后续实现，应以离线图片、音视频附件、分页和大文档内存控制为验收标准。
- 情感分析：当前未内置。聊天正文默认不发送到外部模型；未来若增加，默认应采用
  本地模型并显式显示模型版本、置信度和误差说明。
- 未下载媒体：微信本机没有完整文件时无法凭数据库生成原始内容，会记录为
  `missing`，待微信完成下载后可增量重试。
- 撤回或从本机数据库清除的内容、仅云端存在的内容，不承诺恢复。
- 小程序、转账、位置、通话等复杂卡片目前以安全的文字/结构化摘要为主；不会执行
  卡片内嵌脚本或加载远程资源。

## 隐私边界

- 页面和年度报告无 CDN、远程字体或远程统计脚本。
- 服务固定监听 `127.0.0.1`，每次启动生成随机令牌。
- 常规查询使用 SQLite 只读连接；只有用户主动发起的建库和导出写入受控目录。
- 密钥文件和 SQLite/ZIP 产物使用 `0600`，私有工作目录使用 `0700`。
- URL 仅允许 `http/https`，用户正文使用 DOM `textContent` 或 HTML 转义。
