# Ubuntu 微信个人知识库实施计划

## 目标

把 WeChatMsg-4x 改造成可在 Ubuntu 官方微信 4.x 上运行的本地个人知识库：支持多账号、安全快照、数据库解密、消息浏览与搜索、统计，以及包含图片缩略图和可播放语音的离线 HTML/Markdown 导出。

本机基线：

- Ubuntu 24.04.2 LTS，x86_64
- 腾讯官方 Linux 微信 4.1.13.26
- 微信程序：`/opt/wechat/wechat`
- 微信数据根目录：`/data/wechat/xwechat_files`
- 当前发现两个账号目录，源数据约 1.8 GB
- 源数据库存在活跃 WAL，任何读取都必须先做一致性快照

## 执行原则

1. 永远不修改微信原始数据库和媒体文件。
2. 主程序以普通用户运行；只有读取 `/proc/<pid>/mem` 的最小辅助程序允许临时提权。
3. 所有密钥、解密数据库、导出文件和日志均视为敏感数据。
4. 先完成真实数据的端到端 MVP，再重构前端和知识库能力。
5. 每个阶段必须有可验证的通过门槛；未通过不得用 UI 成果掩盖底层缺口。

## 里程碑 M0：最小可运行 MVP

目标链路：

```text
识别 Linux 微信与账号
→ 获取并校验 SQLCipher 4 密钥
→ 快照 DB/WAL/SHM
→ 解密关键数据库
→ 列出真实会话
→ 导出一个可离线打开、富媒体可交互的 HTML 会话
```

范围：

- [x] Linux 平台导入不再依赖 `winreg`、`ctypes.windll`、`tasklist`、`pywin32`
- [x] 自动识别 `/data/wechat/xwechat_files`，同时支持 `--data-root` 和环境变量覆盖
- [x] 识别两个账号及各自 `db_storage`
- [x] 识别 Linux `wechat`/`weixin` 进程
- [x] 通过 `/proc/<pid>/maps` 和 `/proc/<pid>/mem` 扫描 WCDB literal、salt 锚点与 `Config.Cipher` 对象图
- [x] 所有候选必须通过数据库第一页 HMAC-SHA512 校验
- [x] 快照并解密 `session.db`、`contact.db`、`message_*.db`、`media_*.db`
- [x] 正确合并匹配 WAL 世代的已提交帧并执行完整性检查
- [x] `sessions` 能列出真实会话
- [x] `export --session ... -f html --media` 能生成离线 HTML
- [x] 真实图片展示缩略图，点击打开浏览器通用原图
- [x] 真实 SILK 语音转 MP3，HTML 内直接播放
- [x] 真实 MP4 视频带 poster，HTML 内直接播放
- [x] 内置表情还原为动画 WebP，实测 48 帧
- [x] 链接消息还原为可点击卡片，且仅允许 HTTP(S)
- [x] 加入 Linux 路径、进程扫描、密钥候选、WAL 和解密核心测试

M0 按用户要求已扩展为富媒体 MVP。“复制未解密图片 `.dat`”
或“生成 `.silk` 链接”不计成功；必须能由通用浏览器解码。

## 最终验收标准

- 关键数据库密钥覆盖率 100%，或每个未覆盖库都有可解释分类。
- WAL 中的最新消息不会静默丢失。
- 同一快照重复同步不会生成重复消息。
- 本地存在且可解码的图片显示缩略图；原始 `.dat` 不计成功。
- HTML 中语音可由 Chrome/Firefox 直接播放。
- HTML 和 Markdown 移动目录后仍能通过相对路径访问媒体。
- 导出页面断网可用且无外部请求。
- 10 万条级会话可分页或虚拟滚动浏览。
- 任一单库或单媒体失败不会中断整个同步，并能在报告中定位。

## 风险登记

| 风险 | 等级 | 缓解措施 |
|---|---:|---|
| `/proc/<pid>/mem` 受 Yama 限制 | P0 | 最小提权辅助程序，禁止整个 UI 以 root 运行 |
| Linux 微信密钥形态变化 | P0 | 多种候选策略，最终统一使用 HMAC 校验 |
| Linux V2 密钥派生规则随版本变化 | P1 | kvcomm 多候选+真实样本反验，失败时保留源文件 |
| 媒体未下载到本地 | P1 | 与解密失败分别统计，允许微信补下载后增量重试 |
| 微信升级改变表结构 | P1 | 表结构探测、版本适配器、脱敏夹具回归 |
| 大会话和大导出 | P1 | 分块、内容寻址、懒加载、断点恢复 |
| 隐私泄露 | P0 | 默认离线、本地绑定、权限收紧、日志脱敏、隐私扫描 |
