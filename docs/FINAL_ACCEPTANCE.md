# 阶段验收报告

验收日期：2026-10-16。范围为 Ubuntu 微信 4.x、本机数据目录
`/data/wechat/xwechat_files`、统一档案、现代化本地界面与离线导出。

## 已通过

- 环境：识别 2 个账号；主账号 20 个数据库密钥全部通过 HMAC 校验，20 个库
  全部解密并通过 SQLite 检查。
- 完整性：WAL 按当前世代和最后提交帧合并；同一源快照二次同步跳过扫描，新增 0。
- 档案：首次同步 28 条消息、7 个有消息会话、3,396 个联系人和 9 个附件；
  FTS 中文搜索已实测命中。
- 富媒体：真实会话还原 696×1010 图片、2.232/4.512 秒 MP3、720×1280
  H.264/AAC 视频和 48 帧 WebP 表情；3 个 URL 卡片为安全可点击链接。
- HTML/Markdown：各导出 9 条消息、9 个附件；均有 1 张可点击图片、2 个音频
  播放器、1 个视频播放器和 1 个动态表情，实际解码错误 0。
- Web：随机启动令牌、无令牌 401、严格 CSP、路径穿越拦截；图片 MIME 正确，
  MP3/MP4 Range 请求返回 206 和正确 `Content-Range`。
- M3：首次运行向导、概览、三栏聊天、联系人/群聊、搜索、月份/日期跳转、
  媒体画廊、导出中心、主题和移动端布局均已实现。
- M4：离线年度报告、日历热力图、月/小时分布、收发占比、高频会话、群成员
  排行和本地词频已实现。结构化导出覆盖 HTML、Markdown、JSON、CSV、TXT、
  联系人 CSV、全量消息 CSV和账号隔离 SQLite。
- SQLite 副本：仅 1 个所选账号、28 条消息、9 个附件和 28 条 FTS 记录；9/9
  媒体存在、路径无越界，源机器绝对路径已清除。
- 性能：自动构造 100,000 条消息，分页两页各 80 条且无重复，全文搜索返回
  80 条，年度统计覆盖全部 100,000 条；性能回归通过。
- 安全扫描：`mvp-output` 83 个目录、187 个文件，以及 4 个 ZIP、58 个条目、
  9 个离线页面扫描，权限、ZIP 路径和主动远程资源错误均为 0。
- 自动化：24 项单元、集成、安全与 10 万消息性能测试全部通过。

## 仍需人工确认

- Chrome 与 Firefox 分别在断网状态打开最终 HTML ZIP，进行完整的视觉、拖动
  音视频进度条和下载交互检查。
- Obsidian 与 Typora 分别打开 Markdown ZIP，确认两款应用对 HTML5
  `<audio>/<video>` 标签的具体支持；不支持时仍可点击同包媒体文件。
- Windows 4.x 和 3.x 路径保持兼容代码，但本轮没有 Windows 实机回归。

这些项目没有被计作“已通过”，不影响 Ubuntu MVP 的数据链路与自动化验收结论。

## 已知边界

- 只能导出本机数据库与资源目录仍存在的内容，不能恢复已经清除或仅在云端的数据。
- 小程序、转账、位置、通话等复杂卡片以安全摘要为主，不执行内嵌脚本。
- DOCX 和情感分析尚未实现；完整状态见 `docs/FEATURE_MATRIX.md`。
- Flask 自带服务当前仅用于 `127.0.0.1` 单用户本机访问，不应反向代理到公网。
